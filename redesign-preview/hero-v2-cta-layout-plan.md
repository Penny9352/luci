# Hero V2「立即使用」按钮布局方案

## 1. 文档目的

本文定义 `redesign-preview/hero-v2.html` 首屏 CTA 按钮的布局方案。

目标是把「立即使用」放在：

```text
副标题 与 产品窗口 之间
```

同时保证：

- 不把按钮放进产品窗口内部；
- 不把按钮放到页面底部；
- 不增加产品窗口在页面中的布局高度；
- 不改变产品窗口内部的输入框、品牌标识和动画卡片；
- 不改变产品窗口与下方汇聚线路的相对关系；
- 桌面端和移动端都能稳定显示。

本文只描述方案，不包含实现变更。

## 2. 当前问题

当前页面的外层布局使用 CSS Grid，主要间距来自：

```css
--hero-gap: clamp(2rem, 4vw, 3rem);
```

换算为像素：

```text
G = clamp(32px, 4vw, 48px)
```

其中：

- `2rem = 32px`；
- `3rem = 48px`；
- 中间值随视口宽度变化。

现有按钮使用 `min-height: 3rem`，即 48px。由于页面最小 gap 只有 32px，48px 按钮不可能在所有响应式宽度下完整放入标题和产品窗口之间。

如果把按钮作为普通 Grid 子项，会增加一行布局高度，导致产品窗口及其后续汇聚线路整体下移。

如果把按钮相对于外层 `.hv2` 随意绝对定位，定位参考系过大，按钮会跑到页面底部或其他无关区域。

## 3. 核心方案

### 3.1 定位参考系

新增一个标题组定位层，标题组包含主标题和副标题：

```text
.hv2
├── .hv2__brand
├── .hv2__intro
│   ├── .hv2__head
│   │   ├── h1
│   │   └── p
│   └── .hv2__cta-layer
│       └── .hv2__cta-hit
│           └── .hv2__cta-visual
├── .hv2__console
├── .hv2__matrix
└── .hv2__note
```

`.hv2__intro` 作为 CTA 的定位参考系，不能使用整个 `.hv2` 作为定位参考系。

### 3.2 CTA 不参与布局流

CTA 层使用绝对定位，只负责视觉显示和点击区域，不增加 `.hv2__intro` 的高度：

```text
.hv2__intro 的高度 = 主标题 + 副标题的原始高度
```

因此产品窗口仍然按照原来的 Grid 位置排列，下面的汇聚线路也不需要重新计算。

### 3.3 CTA 的垂直位置

设：

- `G` = 标题组与产品窗口之间的实际 gap；
- `H` = CTA 的视觉高度；
- `Yh` = 副标题底部；
- `Yc` = 产品窗口顶部。

则：

```text
Yc = Yh + G
```

CTA 的中心点放在 gap 中心：

```text
CTA 中心 = Yh + G / 2
```

按钮顶部和底部为：

```text
CTA 顶部 = Yh + (G - H) / 2
CTA 底部 = Yc - (G - H) / 2
```

CSS 定位表达式对应为：

```css
top: calc(100% + var(--hero-gap) / 2);
transform: translate(-50%, -50%);
```

这里的 `100%` 是标题组底部，`var(--hero-gap) / 2` 是标题组到产品窗口间距的一半。

> **定位前提**：上面的 `top` 和 `transform` 必须应用在相对于 `.hv2__intro` 定位的 CTA 元素（或等价的 CTA 视觉层）上。
> 如果 CTA 直接相对于整个 `.hv2` 定位，`100%` 会引用整个 Hero 的高度，按钮会偏到页面下方。

## 4. CTA 尺寸计算

### 4.1 视觉按钮高度

按钮视觉高度不再固定为 48px，而使用：

```css
--cta-visual-height: clamp(2rem, 4vw, 2.5rem);
```

换算为：

```text
H = clamp(32px, 4vw, 40px)
```

这个公式与现有 `hero-gap` 的关系如下：

| 视口宽度区间 | hero-gap G | CTA 视觉高度 H | 结果 |
|---|---:|---:|---|
| ≤ 800px | 32px | 32px | 完整放入，零额外空隙 |
| 800–1000px | 32–40px | 32–40px | 按比例增长，不溢出 |
| 1000–1200px | 40–48px | 40px | 保留至少 0px 间隙 |
| ≥ 1200px | 48px | 40px | 上下各 4px |

核心约束为：

```text
H ≤ G
```

所以 CTA 不会因为高度超过 gap 而覆盖副标题或产品窗口。

### 4.2 点击区域

视觉按钮在窄屏可能只有 32px 高，但点击区域仍应满足 44px 的可操作尺寸。

建议把可点击区域与视觉胶囊分离：

```text
CTA hit area：最小 44px 高
CTA visual：32–40px 高
```

点击区域仍然放在绝对定位层中，不参与布局；视觉按钮在点击区域内垂直居中。

这样既满足触控尺寸，也不会用额外布局高度撑开页面。

### 4.3 按钮宽度

```text
桌面端视觉宽度：132px
移动端视觉宽度：112px
```

按钮内容：

```text
立即使用  →
```

箭头使用现有 SVG 图标系统，不使用 Unicode 箭头替代图标。

### 4.4 参数校验与现状区分

本节中的尺寸是**改造目标值**，不是当前页面的实际值。当前实现使用：

```css
/* 桌面端当前值 */
min-height: 3rem;   /* 48px */
min-width: 8.75rem; /* 140px */

/* 移动端当前覆盖值 */
min-height: 2.625rem; /* 42px */
min-width: 7.5rem;    /* 120px */
```

全局 `box-sizing: border-box` 已生效，因此 `min-height` 表示按钮的最终可见盒高度，
不会再额外叠加 padding。当前 48px 的按钮在 `G = 32px` 的窄屏 gap 中无法完整放置，
这是将 CTA 移出产品窗口并缩小视觉按钮的直接原因。

改造目标使用：

```css
--cta-visual-height: clamp(2rem, 4vw, 2.5rem); /* 32–40px */
```

在根字号为 16px 时：

```text
G = clamp(32px, 4vw, 48px)
H = clamp(32px, 4vw, 40px)
```

因此所有支持的视口下都有 `H ≤ G`：

- 视口宽度 ≤ 800px：`G = 32px`、`H = 32px`；
- 800–1000px：二者按 `4vw` 同步增长；
- 1000–1200px：`H = 40px`、`G = 40–48px`；
- 视口宽度 ≥ 1200px：`H = 40px`、`G = 48px`。

因此视觉按钮不会覆盖副标题或产品窗口。需要单独注意的是，移动端透明点击区域仍要求最小 `44px`，
它可能比 `G = 32px` 高，但点击区域不参与布局；实现时必须让透明区域只接收 CTA 的指针事件，
不能阻挡标题或产品窗口的其它交互。

## 5. 页面高度关系

改造前后，主布局应该满足以下关系。

### 5.1 改造前

```text
品牌行
  + hero-gap
标题区
  + hero-gap
产品窗口
  + hero-gap - 48px matrix margin-top
汇聚线路
```

由于 `.hv2__matrix` 当前有 `margin-top: -3rem`，它会抵消产品窗口到矩阵之间的主要 gap。

### 5.2 改造后

```text
品牌行
  + hero-gap
标题区
  + hero-gap（CTA 视觉上位于这里，不增加高度）
产品窗口（位置不变）
  + hero-gap - 48px matrix margin-top
汇聚线路（位置不变）
```

关键不变量：

```text
产品窗口顶部位置：不因 CTA 增加而下移
产品窗口高度：不变
产品窗口底部：不变
汇聚线路起点：不变
模型图标位置：不变
```

## 6. 视觉层级

CTA 的层级只需要高于页面背景，低于需要覆盖它的产品动画卡片：

```text
普通背景
标题 / 产品窗口
CTA 浮层
动画卡片与结果卡（如有重叠需求）
```

推荐：

- CTA 层：`z-index: 3`；
- 产品窗口：保持现有 `z-index: 2`；
- CTA 不设置大范围发光；
- 使用品牌橙色填充和轻量阴影；
- hover 只做 2px 上移，不改变布局尺寸。

## 7. 响应式规则

### 桌面端

```text
水平居中
视觉高度：40px
视觉宽度：132px
在标题区和产品窗口 gap 的正中显示
```

### 移动端

```text
水平居中
视觉高度：32px 起步
视觉宽度：112px
点击区域仍保持至少 44px
不移入产品窗口内部
不移动汇聚线路
```

移动端如果文字或按钮宽度不足，优先缩小按钮视觉尺寸和水平 padding，不改变产品窗口的内部布局。

## 8. 可访问性要求

- 使用真实的 `<a>` 链接，而不是不可访问的 `<div>` 或 `<span>`；
- 目标地址为 `https://lucimix.com/login`；
- 链接需要有清晰的可访问名称：「立即使用」；
- 保留 `:focus-visible` 焦点样式；
- 点击区域最小高度 44px；
- 箭头 SVG 设置 `aria-hidden="true"`；
- hover、focus、active 状态不能改变周围布局尺寸。

## 9. 实施步骤

1. 移除当前 CTA 位于 `.hv2__console-overlay` 内的定位方式，以及对应的桌面端和移动端旧覆盖规则。
2. 将标题和副标题包进 `.hv2__intro` 定位层。
3. 在 `.hv2__intro` 中增加独立 `.hv2__cta-layer`。
4. 使用 `hero-gap / 2` 将 CTA 锚定到标题和产品窗口之间的 gap 中心。
5. 将按钮视觉高度改为 `clamp(2rem, 4vw, 2.5rem)`。
6. 给 CTA 增加独立的 44px 最小点击区域，并保证它不参与布局、不拦截相邻区域交互。
7. 保持 `.hv2__console`、`.hv2__matrix`、SVG 线路和动画脚本不变。
8. 在桌面、平板、移动端分别检查 CTA 是否位于两个区域中间。

## 10. 验收标准

### 位置

- CTA 必须位于副标题和产品窗口之间；
- CTA 水平居中；
- CTA 不得出现在产品窗口内部；
- CTA 不得出现在汇聚线路或页面底部。

### 布局

- 产品窗口不因 CTA 增加而整体下移；
- 产品窗口高度不变；
- 产品窗口底部和汇聚线路关系不变；
- 六个模型图标位置不变；
- 动画卡片不被 CTA 意外遮挡。

### 响应式

- `H ≤ G` 在所有支持的视口宽度下成立；
- 窄屏按钮不换行；
- 移动端点击区域不小于 44px；
- 页面不存在横向滚动。

### 交互

- 点击「立即使用」进入登录 / 注册页；
- 键盘 Tab 可以聚焦按钮；
- focus-visible 状态清晰可见；
- hover / active 不改变页面布局高度。

## 11. 不在本次方案范围内的内容

- 不重做产品窗口；
- 不修改模型线路路径；
- 不修改模型图标；
- 不调整动画时间线；
- 不改变主标题和副标题文案；
- 不新增其他 CTA 或导航按钮。
