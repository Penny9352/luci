# Lucimix C 端 — 产品基本情况

> 面向新接手同事的产品定位、用户画像、功能结构概述。用于制定国内外运营计划参考。

## 1. 一句话定位

**Lucimix 是一个面向个人用户的 AI 工作台——聊天、文件管理、定时任务、手机端使用，一站式给工作和生活带来价值。同时作为平台，承载开发者上架的外部应用，提供统一的用户体系与计费结算。**

更短的版本：**个人 AI 生产力入口**——聊天是起点，但产出能沉淀、任务能自动化、常用聊天app里也能用。

## 2. 产品定位

### 2.1 功能架构

Lucimix 在四个层面提供价值：

- **模型调度**：提供智能路由（系统自动选模型）、暴力聚合（多模型对比择优）、自定义自选三种模式
- **产出管理**：AI 生成的文件统一汇入文件库（资料库），可搜索、预览、下载、跨对话复用
- **多端覆盖**：网页端 + 微信/飞书/企业微信扫码绑定，手机上对话、文件自动平台同步
- **平台生态**：开发者可上架外部应用，接入 Lucimix 的用户体系与计费结算，集中运营

### 2.2 定位

Lucimix 定位为 **一站式 AI 工作台**：

| 维度 | Lucimix |
|---|---|
| 模型选择 | 智能路由 + 暴力聚合 + 自定义自选 |
| 产出物 | 文件库统一汇总，跨对话复用 |
| 使用场景 | 网页 + 微信/飞书/企业微信，定时任务自动化 |
| 开发者 | API Key 接入用户自有工具；外部应用上架平台，共享用户体系与计费结算 |

## 3. 用户画像

### 3.1 核心定位

用户光谱很宽，从"打开就用"的小白到需要 API 接入的开发者都覆盖。产品原则是：**入口很宽，天花板不低**——入门简单，深度用户也有进阶空间。

> 实际产品首页（个人助手）展示的快捷提问示例覆盖育儿英语启蒙、商务合作邮件、家常菜推荐、区块链科普、家电选购、PDF 文档整理等——工作场景与生活场景并重，印证 Lucimix 定位并非纯职场效率工具，而是"工作 + 生活"双重场景的个人 AI 入口。

### 3.2 典型用户

| 用户类型 | 特征 | 用 Lucimix 做什么 | 用到什么功能 |
|---|---|---|---|
| **纯小白** | 从不关心模型，打开就问 | 写文案、查资料、问问题 | 智能路由、一句话对话 |
| **日常效率型** | 有重复性 AI 需求（日报、信息汇总、文件处理） | 定时生成内容、管 AI 产出 | 智能路由 + 定时任务 + 文件库 |
| **深度用户** | 会挑模型、比较结果、在意产出管理 | 对比模型答案、管理大量 AI 生成文件 | 自定义模型 + 暴力聚合 + 文件库全功能 |
| **技术/开发者** | 有自己的工具链，需要 API 接入 | 在自有工具中调用大模型 | API Key + 自定义模型 + 用量统计 |
| **外部应用商家** | 有 AI 应用产品，需要分发与变现渠道 | 上架应用到 Lucimix 平台，触达平台用户 | 应用接入 + 用户体系打通 + 集中计费结算 |

### 3.3 产品设计原则

- **入口很宽**：小白开箱即用，无需配置直接上手
- **天花板不低**：深度用户有模型选择、文件管理、定时任务、API 等进阶能力
- **端到端闭合**：对话 → 产出 → 管理 → 复用，不依赖外部工具

## 4. 功能结构（用户价值四层）

### 第一层：模型调度
**智能路由、暴力聚合、自定义自选三种模式，覆盖不同使用需求。**

| 功能 | 说明 |
|---|---|
| **智能路由模型**（UI 名称：智能模式） | 系统自动选最合适的单个模型，用户只提问 |
| **暴力聚合模型**（UI 名称：暴力模式） | 同时调多个模型，综合最优结果返回 |
| **自定义自选模型**（UI 名称：自定义模型） | 平台内部模型 + 外部接入模型，手动选择 |

### 第二层：AI 产出可管理
**AI 生成的文件统一汇入文件库，可搜索、预览、下载、跨对话复用。**

| 功能 | 说明 |
|---|---|
| **文件库（资料库）** | 全部 AI 产出 + 用户上传文件汇总一处，去重展示，可搜索/预览/下载；分「全部 / 我的云盘 / 对话内文件 / 图片生成」四个分类 tab，并提供筛选器 |
| **工作区侧栏** | 当前对话的文件实时可见，AI 产出 vs 用户发送分组展示 |
| **从资料库添加到对话** | 不下载再上传，直接从资料库引用文件到新对话 |
| **图片生成** | AI 图片生成能力，在文件库中独立分类展示 |
| **对话历史管理** | 收藏、搜索、重命名、删除对话 |

### 第三层：融入日常场景
**多端覆盖 + 自动化——网页、IM、定时任务。**

| 功能 | 说明 |
|---|---|
| **微信 / 飞书 / 企业微信连接** | 扫码绑定，IM 中直接对话，文件自动同步回网页端 |
| **定时任务** | 创建时可设置：标题（限 25 字）、任务描述（限 500 字，提供引导示例）、执行时间（频率 + 具体时刻，如每天 09:00）、**推送渠道**（结果可直接推送到已绑定的微信等 IM，需先绑定）、**执行模型**（每个任务可单独指定智能模式 / 暴力模式 / 自定义模型，非全局统一） |
| **API Key** | 开发者接入自有工具，OpenAI 兼容格式，用量实时统计 |
| **充值体系** | "光点"积分制，微信/支付宝扫码充值；侧边栏顶部常驻显示当前光点余额，旁附"+"按钮一键快捷充值，无需跳转设置页 |
| **邀请奖励** | 侧边栏首屏常驻入口"邀请好友加入 Lucimix"，邀请人与被邀请人各得 1000 光点（双向奖励） |
| **用量统计** | 按模型/按时间的消耗图表 |

### 第四层：平台生态
**开发者上架外部 AI 应用，用户体系与财务结算由 Lucimix 统一承载。**

| 功能 | 说明 |
|---|---|
| **外部应用上架** | 商家将自有 AI 应用接入 Lucimix 平台，面向平台用户提供服务 |
| **统一用户体系** | 用户用一个 Lucimix 账号即可使用平台内所有应用，无需重复注册 |
| **集中计费结算** | 用户消耗统一走 Lucimix 光点体系，平台与商家之间集中结算 |

## 5. 国际化注意事项

当前 IM 渠道为国内市场配置（**微信 + 飞书 + 企业微信**）。若要拓展海外市场，需替换/新增：

| 国内市场 | 海外对应 |
|---|---|
| 微信 | WhatsApp / Line（日本/台湾/泰国） |
| 飞书 | Slack / Teams |
| 企业微信 | Slack / Teams |

同时需考虑：界面多语言、支付方式（Stripe/PayPal）、短信验证码国际通道、数据合规（GDPR 等）。
